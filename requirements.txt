# ===============================================
# INSTALLATION & SETUP GUIDE
# ===============================================
# 1. Install Python 3.8 or higher
# 2. Create virtual environment:
#    python -m venv venv
#    source venv/bin/activate  # On Windows: venv\Scripts\activate
#
# 3. Install dependencies:
#    pip install -r requirements.txt
#
# 4. Create .env file with environment variables:
#    SECRET_KEY=your-secret-key-here
#    DATABASE_URL=sqlite:///urban_platter.db  (or PostgreSQL/MySQL)
#    STRIPE_SECRET_KEY=sk_test_your_stripe_key
#    DEBUG=False (for production)
#
# 5. Initialize database:
#    python -c "from urban_platter_app import app, db; app.app_context().push(); db.create_all()"
#
# 6. Run development server:
#    python urban_platter_app.py
#    OR
#    flask run
#
# 7. Access application:
#    Local: http://localhost:5000
#    Demo Credentials:
#    - Admin: admin@urbanplatter.com / admin123
#    - Staff: staff@urbanplatter.com / staff123

# ===============================================
# API ENDPOINTS
# ===============================================
# Public endpoints:
#   GET  /                          - Homepage
#   GET  /menu                      - Menu display
#   POST /register                  - User registration
#   POST /login                     - User login
#   GET  /logout                    - User logout
#   GET  /api/menu_items            - Menu items API
#
# Customer endpoints (require login):
#   POST /order                     - Place new order
#   GET  /orders                    - View customer orders
#   GET  /order-confirmation/<id>   - Order confirmation page
#   POST /reservations              - Make reservation
#   GET  /customer/dashboard        - Customer dashboard
#
# Staff endpoints (require Staff/Admin role):
#   POST /orders/<id>/status        - Update order status
#   GET  /staff/dashboard           - Staff dashboard
#   POST /reservations/<id>/status  - Update reservation status
#
# Admin endpoints (require Admin role):
#   GET  /admin/dashboard           - Admin dashboard
#   GET  /admin/menu                - Menu management
#   POST /admin/menu/add            - Add menu item
#   POST /admin/menu/edit/<id>      - Edit menu item
#   GET  /admin/menu/delete/<id>    - Delete menu item
#   GET  /admin/reservations        - Reservation management
#   GET  /admin/reports             - Reports page
#   GET  /admin/reports/sales       - Sales report (JSON/CSV)

# ===============================================
# TROUBLESHOOTING
# ===============================================
# Issue: "No module named 'flask'"
# Solution: Activate virtual environment and run: pip install -r requirements.txt
#
# Issue: "Database locked"
# Solution: Use PostgreSQL for concurrent access instead of SQLite
#
# Issue: "Stripe payment fails"
# Solution: Verify STRIPE_SECRET_KEY in .env file
#
# Issue: "Images not loading"
# Solution: Ensure static/images directory exists with menu item images
#
# Issue: "Server errors in production"
# Solution: Check logs in Elastic Beanstalk console or server logs

# ===============================================
# SECURITY BEST PRACTICES
# ===============================================
# 1. Never commit .env file or secrets to version control
# 2. Use environment variables for sensitive data
# 3. Set DEBUG=False in production
# 4. Use HTTPS in production
# 5. Implement rate limiting for API endpoints
# 6. Validate all user inputs
# 7. Use parameterized queries (SQLAlchemy does this)
# 8. Keep dependencies updated
# 9. Use strong SECRET_KEY (generate with: python -c "import secrets; print(secrets.token_hex(32))")
# 10. Implement CORS properly if accessed from multiple domains
